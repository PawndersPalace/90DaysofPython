# Contributing

Thanks for helping make 90 Days of Python more useful and welcoming.

## Ways to contribute

- Report a typo, unclear instruction, or broken example by opening an issue.
- Suggest a change to the curriculum or add an optional practice prompt.
- Share a beginner project you made with the course.
- Improve an example while keeping it appropriate for someone new to Python.

## Before opening a pull request

1. Keep changes focused and explain what they help a learner do.
2. Use plain language and define unfamiliar terms.
3. If you change runnable Python, run it with Python 3.10 or newer.
4. For a lesson change, include the expected result or a way for a beginner to
   check their work.
5. Never include API keys, passwords, private data, or other secrets.

You can open a pull request from a fork using GitHub's web interface. Small,
beginner-friendly contributions are welcome; you do not need to be an expert.
