# Day 1: Your first Python program

## Goal

Run a Python file, change its code, and see the result.

## Run it

From the repository folder, open a terminal and run:

```sh
python lessons/day-01/main.py
```

If that command is not found, try `py lessons/day-01/main.py` on Windows or
`python3 lessons/day-01/main.py` on macOS and Linux.

You should see:

```text
Hello, Python!
I'm Python learner, and I'm here to build useful things.
```

## What is happening?

- A Python program is a set of instructions that Python runs from top to
  bottom.
- `print(...)` displays text in the terminal.
- Text surrounded by quotes is called a string.
- `name = "Python learner"` stores a value in a variable named `name`.
- An f-string, written like `f"Hello, {name}"`, inserts a variable's value
  into text.

## Try it yourself

1. Change the first message and run the file again.
2. Change the `name` and `goal` values.
3. Add a variable for another thing you want to learn and print it in an
   f-string.
4. Make a deliberate typo, run the program, and read the error. Then fix it.

Keep your version in your own work folder or a fork so you can look back at
your progress.
